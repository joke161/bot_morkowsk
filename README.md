# Bot Morkowsk v4.0 — Автоматизация Ozon «Морковск» для LDPlayer 9

Решение класса RPA (Robotic Process Automation), предназначенное для автоматического выполнения игровых активностей и фарма в мини-игре **«Морковск»** внутри мобильного приложения **Ozon** на эмуляторе **LDPlayer 9**.

Скрипт оптимизирован для стабильной работы в режиме **24/7** на Windows 10/11, поддерживает последовательную обработку нескольких аккаунтов (по умолчанию до 3-х), использует алгоритмы компьютерного зрения для навигации и технологии оптического распознавания текста (OCR) для фильтрации заданий.

---

## 🌟 Ключевые особенности

* **Многопоточный Anti-Detect (Антифрод)**: 
  * Начальная рандомизированная задержка перед стартом сессии (от 1 до 300 секунд) для предотвращения детекции по таймингу.
  * Индивидуальные человекоподобные задержки (от 1.5 до 3 секунд) между кликами и действиями.
  * Случайные интервалы ожидания (от 10 до 180 секунд) между переключениями аккаунтов.
* **Умное распознавание заданий (EasyOCR)**:
  * Бот автоматически сканирует список заданий и выполняет только бесплатные задания (содержащие маркер `Посетите`).
  * Полностью игнорирует платные задания (содержащие маркеры: `Купите`, `заказе`, `подборки`, `рублей`).
  * Автономный режим EasyOCR: модели хранятся локально в `easyocr_models`, что исключает постоянные сетевые запросы при инициализации.
* **Автоматизация заданий типа «Корзина»**:
  * Реализован умный сценарий для заданий вида *"Добавьте товар в корзину"* с поиском кнопки добавления, свайпом ленты товаров и возвратом к списку.
* **Отказоустойчивость и Dynamic Waiting (Explicit Wait)**:
  * Взаимодействие с UI элементами контролируется динамическим ожиданием (`wait_for_element`) вместо жестких пауз.
  * Автоматический перехват и обход системного окна *"Приложение Ozon не отвечает"* (клик по кнопке "Подождать").
  * Безопасный сброс состояния (`safe_state_reset_to_tasks`): при потере фокуса или сбое бот возвращается в точку старта без жестких перезапусков.
* **Аварийный выключатель (Kill-Switch)**:
  * Комбинация клавиш `Ctrl + Shift + K` мгновенно закрывает активный эмулятор и завершает работу скрипта.
* **Интегрированный планировщик**:
  * Автоматический ежедневный запуск в заданное время (например, в `01:00`). Защита от повторного запуска в одни сутки.

## 🛠️ Стек технологий

* **Язык**: Python 3.11 / 3.12
* **Автоматизация UI**: `pyautogui` (управление курсором, клики, свайпы)
* **Компьютерное зрение**: `opencv-python` (поиск шаблонов кнопок по изображениям)
* **OCR**: `easyocr` (детектирование и распознавание текста заданий)
* **Планирование задач**: `schedule`
* **Перехват горячих клавиш**: `keyboard`
* **Управление эмулятором**: `subprocess` (консольные вызовы `ldconsole.exe`)

## ⚙️ Предварительная настройка

### 1. Настройка эмуляторов LDPlayer 9
* Установите **LDPlayer 9**.
* Создайте необходимое количество копий эмулятора в LDMultiPlayer (индексы `0, 1, 2` для 3 аккаунтов).
* Настройте **каждое** окно эмулятора строго на следующие параметры:
  * **Разрешение**: Мобильная версия (Телефон) -> `720x1280` (DPI `320`).
* В каждом эмуляторе установите приложение **Ozon** и авторизуйтесь под соответствующими аккаунтами.

### 2. Настройка путей в `bot.py`
Откройте файл `bot.py` и при необходимости скорректируйте константы конфигурации в блоке `Настройки` (строки 25–96):
* `LDCONSOLE_PATH`: Полный путь к файлу управления эмулятором (по умолчанию `C:\LDPlayer\LDPlayer9\ldconsole.exe`).
* `ACCOUNTS_COUNT`: Количество обрабатываемых аккаунтов (по умолчанию `3`).
* `START_TIME`: Время ежедневного автоматического запуска бота (по умолчанию `"01:00"`).

## 🚀 Запуск проекта

Для запуска бота на Windows выполните двойной клик по файлу:
```bash
run.bat
```
Данный скрипт автоматически:
1. Проверит наличие виртуального окружения Python (`.venv`). Если его нет, он использует глобальный интерпретатор Python.
2. Проверит и установит недостающие зависимости из `requirements.txt`.
3. Запустит бота `bot.py`.

При запуске консоль предложит выбрать режим работы:
* **`[1] Запустить фарм СЕЙЧАС`** — бот немедленно начнет выполнение цикла для всех аккаунтов, после чего перейдет в режим ожидания расписания на следующие дни.
* **`[2] Ждать расписание`** — бот сразу перейдет в режим ожидания назначенного в `START_TIME` времени.

## 💾 Офлайн-настройка EasyOCR (без интернета)

При первом запуске EasyOCR пытается скачать языковые модели из сети. Если у вас нестабильный интернет, включен VPN или скачивание блокируется, бот может выдать ошибку инициализации OCR.

Чтобы настроить модели вручную:
1. Создайте папку `easyocr_models` в корневой директории проекта (если ее нет).
2. Скачайте модель детектора текста:  
   👉 [craft_mlt_25k.zip](https://jaided.ai/read_download/craft_mlt_25k.zip)  
   *Распакуйте архив и поместите файл `craft_mlt_25k.pth` в папку `easyocr_models`.*
3. Скачайте модель распознавания (русский язык):  
   👉 [cyrillic_g2.zip](https://jaided.ai/read_download/cyrillic_g2.zip)  
   *Распакуйте архив и поместите файл `cyrillic_g2.pth` в папку `easyocr_models`.*
